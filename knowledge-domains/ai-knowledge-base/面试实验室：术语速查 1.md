# 面试实验室：术语速查 1

术语按原资料顺序整理；先解释概念，再结合对应问答理解应用。模型、工具和业务状态是不同层次，不能用同一个词代替全部职责。

## 词元 · Token

模型编码与生成使用的离散单位，具体切分由 tokenizer 决定，不能用固定的字符或词比例准确换算。

## 上下文窗口 · Context window

模型单次调用能看到的最大 token 数（输入 + 输出）。

## 温度 · Temperature

采样的随机程度。越低越稳定，工具选择时更合适。

## 结构化输出 · Structured output

强制模型输出符合某个 JSON Schema。

## 幻觉 · Hallucination

语句流畅但没有依据的输出。

## 向量嵌入 · Embedding

表示语义的一串数字；语义相近，向量就相近。

## 余弦相似度 · Cosine similarity

基于两个向量夹角的相似度。

## 系统提示词 · System prompt

位于用户输入之上的常驻指令。

## Prompt caching / KV cache

复用重复 prompt 前缀的计算结果，更便宜、更快。

## 推理模型 · Reasoning model

回答前先“思考”（生成隐藏推理）的模型。难题更强，但更慢、更贵。

## 自注意力 · Self-attention

每个 token 参考前面所有 token 来构建自己的表示。

## Pretraining / SFT / RLHF / DPO

学语言 → 学会遵循指令 → 学习偏好（RLHF 用强化学习循环 / DPO 直接优化）。

## LoRA / QLoRA

只微调小的低秩适配器而不是全部权重（QLoRA：基座模型以 4-bit 存储）。

## 量化 · Quantization

用更少的比特存权重（int8/int4）：更小更快，质量略有损失。

## 首 token 延迟 · TTFT

首个 token 的等待时间，主要由 prompt 长度（prefill）决定。

## 检索增强生成 · RAG

先检索证据，再让 LLM 基于证据回答。

## 分块/重叠 · Chunking / overlap

把文档切成可检索的片段，并在边界处保留少量重叠。

## 关键词检索 · BM25

基于词频、词的稀有度和文档长度的关键词相关性算法。

## 稠密/向量检索 · Dense retrieval

按 embedding 相似度检索。

## 近似最近邻 · ANN / HNSW

快速的近似向量检索，用少量召回换速度。

## 混合检索 · Hybrid search

关键词检索 + 向量检索的结合。

## 倒数排名融合 · RRF

得分 = 各结果列表中 Σ 1/(k + 排名)。

## 重排序 · Reranker

对候选短名单做更慢但更精确的第二轮排序。

## Bi-encoder vs cross-encoder

查询和文档分开编码（快）vs 一起编码（准）。

## 查询改写 · Query rewrite / multi-query

生成多种改写查询以提高召回。

## HyDE

用“假设的答案”的 embedding 去检索，而不是问题本身。
