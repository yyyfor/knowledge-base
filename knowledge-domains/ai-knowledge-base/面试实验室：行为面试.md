# 面试实验室：行为面试

本章收录面试实验室的完整问答，保留题号与英文问题。实现细节来自独立的学习示例项目，不代表现有小程序已部署这些功能，也不代表读者已有相关经历；面试回答应替换为自己的真实实践。

## K1 · 讲一个技术权衡的例子。

英文问题：Tell me about a technical trade-off.

RRF vs 加权分数融合，或在应用层融合 vs 在 Elasticsearch 中融合。

## K2 · 讲一次失败的经历。

英文问题：Tell me about a time something failed.

小模型跳过了 calculate → required_tools。或者召回率 1.0 而引用准确率 0.5 → 分开评估。或者 JSON Schema 让 Ollama 的语法编译失败 → 逐个关键字二分排查、扁平化 schema、加回归测试。

## K3 · 讲一个你愿意向质疑者辩护的设计。

英文问题：Tell me about a design you'd defend to a skeptic.

节点以请求人而不是审批人的身份运行；verify 和 approve 放在 execute 之前；先查账本再判断过期。

## K4 · 你如何快速学习一个新领域？

英文问题：How do you learn a new area fast?

按周计划推进，每周一个可运行的 commit，每个 lab 写一页 ADR，并做计时的口头回答。

## K5 · 你如何决定到底要不要用 Agent？

英文问题：How would you decide whether to use an agent at all?

Workflow 优先的原则，加上测量：用评估套件比较确定性路径与自主路径。
