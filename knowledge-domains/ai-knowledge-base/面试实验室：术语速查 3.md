# 面试实验室：术语速查 3

术语按原资料顺序整理；先解释概念，再结合对应问答理解应用。模型、工具和业务状态是不同层次，不能用同一个词代替全部职责。

## 状态图 · State graph

在共享且带 checkpoint 的状态上，由节点（步骤）和边（路由）组成的图。

## Handoff vs agent-as-tool

把控制权交给另一个 agent / 像调用函数一样调用另一个 agent。

## 多智能体 · Multi-agent

多个由模型驱动的循环协作。

## MCP

一个开放协议，向 AI 应用暴露工具、资源和提示模板。

## A2A

Agent 与其他 Agent 通信的协议。

## 提示注入 · Prompt injection (direct / indirect)

来自用户的恶意指令 / 藏在文档或工具输出里的恶意指令。

## 轨迹 · Trajectory

一次 run 中所有步骤和工具调用的完整序列。

## 黄金测试集 · Golden set

有已知正确答案或来源的固定测试问题集。

## Recall@K / Precision@K

相关项有多少出现在前 K 个 / 前 K 个中有多少是相关的。

## MRR

每个问题先计算第一个相关结果排名的倒数，无命中计零，再对多个问题求平均。单题倒数排名不是整个测试集的 MRR。

## NDCG

奖励相关结果排在前面的排序质量分数。

## 忠实度 · Faithfulness

回答是否被给定的上下文支持？

## Citation accuracy

引用的标识、原文、来源及论断支持关系是否正确；标识存在或文本匹配只是必要检查，不足以证明语义支持。

## LLM-as-judge

用模型给输出打分。有偏差，必须校准。

## 回归门禁 · Regression gate

指标相对基线下降时阻止发布。

## 链路/跨度 · Trace / span

一次请求的记录 / 其中一个计时步骤。

## P95 latency

95% 的请求比这个值快。

## SLI / SLO / SLA

度量指标 / 内部目标 / 对客户的正式承诺。

## RBAC / ABAC / ACL

基于角色 / 基于属性 / 按资源的访问列表。

## 租户 · Tenant

相互隔离的客户或组织边界。

## 最小权限 · Least privilege

每个组件只拥有它需要的权限。

## pass@k / pass^k

k 次中至少一次成功 / k 次全部成功（衡量可靠性）。

## 工具投毒 · Tool poisoning

藏在工具描述或输出中的恶意指令。

## OWASP LLM Top 10

LLM 应用风险的标准清单。
