## J1 · 最小的 Agent 循环（约 25 行，不绑定厂商）

英文问题：Minimal agent loop (about 25 lines, vendor-neutral)

```python
def run_agent(goal, tools, call_model, max_steps=6):
    history = []
    for _ in range(max_steps):
        action = call_model(goal=goal, history=history,
                            tool_schemas={n: t.schema for n, t in tools.items()})
        if action["tool"] == "finish":
            return {"status": "completed", "answer": action["answer"]}
        tool = tools.get(action["tool"])
        if tool is None:                                   # 白名单
            history.append({"error": "unknown_tool"}); continue
        try:
            args = tool.validate(action["arguments"])      # 严格 schema
        except ValueError as e:
            history.append({"error": "invalid_arguments", "detail": str(e)}); continue
        if tool.risk != "read_only":                       # 人工审批
            return {"status": "awaiting_approval", "pending": {"tool": action["tool"], "args": args}}
        try:
            result = tool.run(args)
        except TimeoutError:
            history.append({"tool": action["tool"], "error": "timeout"}); continue
        history.append({"tool": action["tool"], "result": result})
    return {"status": "max_steps"}
```

准备好继续补充：token 预算、超时、每步后持久化状态，以及写操作的幂等键。

## J2 · RRF

英文问题：RRF

RRF 对每路去重后的排名累加 1/(smooth+rank)，排名从 1 开始；smooth 是平滑常数，不是 top-k。下面使用字符串 ID，并对并列分数按 ID 排序。

```python
def reciprocal_rank_fusion(rankings, smooth=60):
    if smooth < 0:
        raise ValueError("smooth must be non-negative")
    scores = {}
    for ranking in rankings:
        for rank, doc_id in enumerate(dict.fromkeys(ranking), 1):
            scores[doc_id] = scores.get(doc_id, 0.0) + 1 / (smooth + rank)
    return sorted(scores, key=lambda doc_id: (-scores[doc_id], doc_id))
```

练习核对：[[A,B,A],[B,C]] 应融合为 [B,A,C]；重复 A 不增加额外得分。还需测试空列表、并列与非法平滑常数。

## J3 · Recall@K、MRR、NDCG

英文问题：Recall@K, MRR, NDCG

区分单题的倒数排名与多题平均 MRR；下面使用二值相关性，相关集为空时本练习约定返回 0，正式评估需明确是否将此类问题单独统计。

```python
from math import log2

def recall_at_k(retrieved, relevant, k):
    if k <= 0 or not relevant:
        return 0.0
    return len(set(retrieved[:k]) & set(relevant)) / len(set(relevant))

def reciprocal_rank(retrieved, relevant):
    return next((1 / rank for rank, item in enumerate(retrieved, 1)
                 if item in relevant), 0.0)

def mean_reciprocal_rank(cases):
    return sum(reciprocal_rank(ids, rel) for ids, rel in cases) / len(cases) if cases else 0.0

def ndcg_at_k(retrieved, relevant, k):
    if k <= 0 or not relevant:
        return 0.0
    seen = set()
    dcg = 0.0
    for rank, item in enumerate(retrieved[:k], 1):
        if item in relevant and item not in seen:
            dcg += 1 / log2(rank + 1)
        seen.add(item)
    ideal = sum(1 / log2(rank + 1) for rank in range(1, min(k, len(set(relevant))) + 1))
    return dcg / ideal
```

retrieved=[B,A,C]、relevant={A} 时，Recall@3=1，单题倒数排名=0.5，NDCG@3=1/log2(3)≈0.6309。重复命中不能重复获得相关性增益。

## J4 · 带退避和抖动的重试

英文问题：Retry with backoff and jitter

```python
import random, time
def with_retry(fn, retries=3, base=0.5, retryable=(TimeoutError, ConnectionError)):
    for attempt in range(retries + 1):
        try:
            return fn()
        except retryable:
            if attempt == retries:
                raise
            time.sleep(base * 2 ** attempt * random.uniform(0.5, 1.5))
```

追问：“这对支付调用安全吗？”只有配合幂等键才安全。

## J5 · 余弦相似度和朴素的 top-k 向量检索

英文问题：Cosine similarity and a naive top-k vector search

余弦相似度是点积除以两个向量的范数乘积。零向量没有定义良好的余弦相似度，本练习拒绝它。查询和文档必须处于兼容嵌入空间。

```python
from math import sqrt, isfinite

def cosine(a, b):
    if not a or len(a) != len(b) or not all(isfinite(x) for x in [*a, *b]):
        raise ValueError("incompatible or invalid vectors")
    na, nb = sqrt(sum(x*x for x in a)), sqrt(sum(x*x for x in b))
    if na == 0 or nb == 0:
        raise ValueError("zero vector")
    return sum(x*y for x, y in zip(a, b)) / (na * nb)

def top_k(query, documents, k):
    if k < 0:
        raise ValueError("k must be non-negative")
    scores = [(doc_id, cosine(query, vector)) for doc_id, vector in documents]
    return sorted(scores, key=lambda pair: (-pair[1], pair[0]))[:k]
```

计算所有相似度需要 O(N·d)，全排序额外 O(N log N)，d 为维度。用大小 k 的堆可减少排序成本到 O(N log k)。ANN 索引是另一种以近似召回换速度的方法，不保证每种负载都获得固定数量级的提升。
