# 文档智能与人工复核

文档智能（Document Intelligence）把文件中的文字、版面、表格和字段转换成可验证的结构化信息。它与 RAG 不同：RAG 为问题寻找证据，文档抽取则按照预定字段模式组织资料，两者可以共享解析结果。

## 入门：解析与抽取的区别

解析识别文字、阅读顺序、页码和表格结构；抽取识别某个业务字段的值。文本层 PDF 可以直接提取文字，扫描件走 OCR；多栏页面、合并单元格和跨页表格都需要保留版面信息，不能简单按屏幕坐标拼成一段。

JSON Schema 是结构化数据的约束规范，可声明字段类型、必填项和范围。但输出符合 Schema 只说明形状正确，不说明字段值真实。未知字段返回明确空值或待核验状态，而不是猜一个看起来合理的值。

## 进阶：每个字段带证据

抽取结果保存 field、value、documentVersion、page、bbox 和 quote。bbox（Bounding Box，边界框）标记原文位置，同时注明坐标系、页面尺寸和单位，避免前端高亮错位。保留原始文本与规范化值，例如原文日期和统一后的 ISO 日期。

校验分三层：类型与格式、同一文档内的逻辑关系、多份文档之间的一致性。校验位、日期范围、合计数和来源有效性都应由程序或权威系统核对。模型给出的 0.95 不能直接当作字段正确率 95%。

## 项目实践：三字段抽取器

选择一种公开或合成文档，只抽文档标题、发布日期、版本号。输入先经过文件类型、大小和恶意文件检测；保存文件哈希及解析版本。输出草稿进入复核界面，点击字段能定位原文，用户修改后才写入 confirmedValue（已确认值）。

模型结果写 suggestedValue（建议值），人工确认记录操作者、修改前后值、证据和时间。低清晰度、缺证据、跨文档冲突或关键字段缺失自动进入复核队列。这是练习架构，不表示现有小程序已经有 OCR 或自动审核功能。

## 高阶：证据、隐私与业务决定

外部文档中的命令不能成为系统指令。即使加了分隔符，也要在工具权限和写入接口上限制模型；敏感决定不由生成文本直接生效。模型只能提出建议，业务审批由受授权的人或确定性规则完成。

只向模型发送任务需要的字段与片段。日志中的个人信息同样受访问、保留和删除策略约束；脱敏不能只隐藏界面而保留无限期原文日志。用字段级准确率、证据定位准确率、人工修改率和复核耗时评估，不用无法证明的“零错误”承诺。
