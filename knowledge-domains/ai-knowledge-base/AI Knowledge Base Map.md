## How to Use

- Beginner：先理解 Agent、Workflow、AI Coding、Context Engineering 和 Skills 的区别。
- Intermediate：重点看真实工作流如何拆解、如何验证、如何沉淀模板和 checklist。
- Advanced：关注 Harness、Eval、Tracing、权限、安全、恢复、成本和治理。

## Suggested Learning Path

- 先看 [[AI Agent and AI Coding Knowledge Synthesis]]，建立 Agent 与 AI Coding 的统一框架。
- 再看 [[Agent Architecture and Engineering Practice]]，补 Agent Loop、Harness、Context、Tools、Memory、Tracing 和 Recovery。
- 非技术使用者继续看 [[AI Coding for Non Technical Users]]，把 AI Coding 落到日常工作流。
- 团队培训或分享时看 [[Agent Presentation Training Notes]]，把公开分享转成内部知识资产。
- 如果要做系统设计，继续看 [[Senior Architecture Decision Framework]] 和 [[Cross-Domain System Flow Patterns]]。
