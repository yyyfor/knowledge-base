# 面试实验室：术语速查 2

术语按原资料顺序整理；先解释概念，再结合对应问答理解应用。模型、工具和业务状态是不同层次，不能用同一个词代替全部职责。

## 元数据过滤 · Metadata filter / pre-filter

在检索过程中按租户、日期、ACL 等字段过滤。

## Parent-child retrieval

用小片段匹配，再返回它所属的大段落。

## GraphRAG

用实体-关系遍历作为证据。

## 多跳 · Multi-hop

需要串联多个事实才能回答：A→B→C。

## 本体/分类体系 · Ontology / taxonomy

实体类型与关系的模式 / 分类层级。

## 实体消歧/合并 · Entity resolution

判断两条记录是否指向同一个真实实体。

## 智能体 · Agent

一个循环：模型选择下一步动作，应用执行，结果反馈回来，直到满足停止条件。

## 工作流 · Workflow

在代码中预先定义好的路径；LLM 负责填充步骤，但不决定路线。

## 工具调用 · Tool / function calling

模型以结构化数据提出调用，由应用执行。

## 工具契约 · Tool schema / contract

名称、描述、带类型的参数/结果，以及副作用和权限规则。

## 动作/观察 · Action / observation

模型请求做什么 / 工具返回了什么。

## ReAct

推理 → 行动 → 观察，循环往复。经典的 Agent 模式。

## Plan-and-execute

先制定完整计划，再逐步执行。

## Reflection / evaluator-optimizer

模型评审自己的输出并修改。

## 状态 · State

任务的权威进度，存在数据库里。

## 上下文 · Context

模型这一次调用看到的内容。

## 记忆 · Memory

跨轮次或跨 run 有选择地保存的信息。

## Context engineering

精确决定每一步放进上下文的内容。

## 检查点 · Checkpoint

持久化的快照，使 run 可以暂停或恢复。

## 人在回路 · HITL

由人批准、修改或拒绝高风险动作。

## 护栏 · Guardrail

对输入、输出或行为的检查。

## 授权 · Authorization

这个身份是否可以执行这个动作。

## 幂等键 · Idempotency key

唯一 ID，让重复请求不会重复产生效果。

## 执行账本/回执 · Execution ledger / receipt

动作已经发生的持久记录。

## 补偿 · Compensation / saga

无法回滚时，用新的动作抵消已产生的效果。

## 持久化执行 · Durable execution

能在崩溃后从中断处恢复的工作流。
