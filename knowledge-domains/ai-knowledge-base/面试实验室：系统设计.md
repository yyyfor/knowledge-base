# 面试实验室：系统设计

本章收录面试实验室的完整问答，保留题号与英文问题。实现细节来自独立的学习示例项目，不代表现有小程序已部署这些功能，也不代表读者已有相关经历；面试回答应替换为自己的真实实践。

## H1 · 设计一个能退款的客服 Agent。

英文问题：Design a customer-support agent that can issue refunds

工具分为 get_order（只读）、search_policy（只读检索）、draft_reply（草稿）、issue_refund（外部写）与 send_email（外部写）。权限来自当前用户，订单读取不能跨用户。退款上限由服务端策略决定，高风险动作显示精确金额、收款对象和依据供人工批准。以 order_id 与 refund_intent_id 形成稳定幂等键，支付提供方去重，保存意图与回执；checkpoint 只恢复进度，不能独自防止重复退款。对未知执行结果先查证，再重试或人工处理。用正常、重复请求、超时、注入与权限撤销工单评估，重点关注错误退款、未授权写入和任务费用。

## H2 · 设计一个企业知识助手 Agent。

英文问题：Design an enterprise knowledge assistant agent

这就是放大规模后的示例项目：摄取走队列和 worker；混合检索 + 图检索位于带 ACL 和治理过滤的 Knowledge API 之后；Agent runtime 有 checkpoint、工具白名单、连接内部系统的 MCP 以及写操作审批；评估服务带基线闸门；全链路 trace。要讲清 Knowledge 平台与 Agent 平台的边界、多租户以及通过 alias 回滚的版本化索引。
